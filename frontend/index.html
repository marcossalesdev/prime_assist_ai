Conexão da API do Gemini

O PrimeAssist AI utiliza o modelo de linguagem Gemini 1.5 Flash da Google AI Studio. Para gerar as respostas em linguagem natural, é necessário configurar sua chave de API pessoal.

Sua chave é salva apenas localmente no seu navegador e enviada de forma segura nas requisições.

Como obter uma chave?

  1. Acesse o Google AI Studio.
  2. Faça login com sua conta Google.
  3. Clique em "Get API Key" no menu lateral superior.
  4. Crie uma nova chave de API (Create API Key).
  5. Copie o código gerado e cole no painel ao lado.
